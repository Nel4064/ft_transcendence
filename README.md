This project aim to use a fully typed TypeScript stack, from the frontend to the database. The application is containerized for easy deployment and reproducible environments.

Frontend:
TypeScript
React + Vite

Backend:
TypeScript
NestJS

Database:
PostgreSQL

ORM:
Prisma 7

Real-time:
Socket.io

Deployment:
Podman
